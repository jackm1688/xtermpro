S3 功能介绍 · 在桌面工作台管理对象存储

XTermPro 的 S3 功能面向运维、开发和备份人员，将服务凭据、连接、对象浏览、文件传输与同步计划集中到图形工作区。既可连接 AWS S3，也可按服务兼容性接入对象存储；本指南给出五种环境的配置参考，不代表五种环境均已完成验收。

使用路径：创建或导入托管凭据 → 新建 S3 连接 → 打开对象浏览 → 上传、下载或预览同步 → 查看任务结果和失败原因。具体能力、配置方法与限制见本文各章节。

功能区域提供什么能力用户得到的价值
托管 S3 凭据集中维护 Endpoint、Region、寻址、HTTPS、AK/SK 及可选 Token；本地加密保存；连接引用凭据，不复制秘密。多个连接复用一组配置，减少重复输入和连接文件散落密钥；新操作读取当前凭据版本。
连接与网络路径连接设置默认桶、前缀、只读标志；支持 Direct 与独立 SSH Route Proxy。按环境与业务保存入口；本机不能直接访问存储时，可经具备访问条件的 SSH 路由访问。
对象浏览目录树、当前目录直接文件、文件名包含搜索、分页、大小与本机时区修改时间；查看扫描范围内文件数。不必在长串对象 Key 中查找目标，便于定位日志、报表和备份文件。
上传下载与传输任务单文件、多文件和目录递归；流式处理、大对象分片；进度、取消、逐项结果及安全恢复。在一个工作区完成收发并定位失败项，减少整批重做与覆盖误操作。
对象与桶管理对象属性、ACL、复制、移动、删除、递归预览；创建桶、删除空桶、用量扫描与目录标记。完成常见整理操作，并在批量变更前核对范围。实际能力仍由云端权限及服务兼容性决定。
同步任务本地→S3、S3→本地、同服务 S3→S3；先生成计划，支持过滤、跳过已有项和可选删除。把一批文件的传输、跳过和删除显式列出，先检查再执行。

解决什么问题

常见问题S3 工作区的处理方式适用边界
各连接反复填写密钥，轮换后容易漏改凭据与连接分离；多个连接引用同一凭据，新操作读取最新版本。不自动从 IAM/SSO 获取凭据；临时凭据到期后仍需更新。在途任务不会悄悄切换密钥。
只能看到桶名，不清楚对象在哪里按 Key 构建目录树，结合当前目录搜索、前缀和分页浏览。对象存储目录是前缀；初次扫描大范围可能较慢，可取消；统计不是远端原子快照。
批量上传下载失败后，不知道哪些完成传输任务显示逐项成功、失败、跳过和暂停原因。异常退出仅对安全项自动恢复；单个未完成文件从头重传，不承诺字节断点续传。
同步或递归清理容易误删先扫描生成计划，核对范围和明细；同步删除默认关闭，启用后另行确认。移动与批量操作不是事务；源变化、冲突或失败可能保留部分结果，应查看逐项反馈。
私有存储只能从指定网络访问连接引用独立 SSH Route Proxy，将本机 S3 请求和本地文件传输经 SSH 隧道路由。代理失败不会自动直连；不是在远端执行上传命令，也不会自动扩大网络或存储权限。
权限或配置错误只有笼统失败提示显示可安全取得的错误分类、HTTP 状态、请求阶段和请求 ID 等上下文。不输出秘密和原始错误正文，不绕过拒绝策略；可列桶不等于有对象读取或写入权限。

应用场景 · 从配置到结果

以下为使用场景示例，不代表已在你的业务环境验证通过。桶名、对象名和前缀均需替换。

场景与目标操作路径预期结果与检查点
运维日志与扫描报表归档建立业务连接，选择 logs/demo/ 前缀 → 上传非敏感测试文件或目录 → 查看传输任务。核对对象 Key、大小和逐项完成状态，再下载核对内容；失败项有明确原因。需要写权限。
备份文件下载与恢复准备创建只读连接 → 浏览备份前缀 → 搜索目标文件 → 下载到空本机目录。确认所选对象与内容正确；默认不覆盖已有文件。这里只完成文件取回，不代表数据库恢复或业务恢复通过。
项目资料批量发布同步任务选择本地→S3，目标为 release-demo/，排除 *.tmp → 生成预览 → 核对后执行。预览无写入，执行后查看传输/跳过/失败项；默认不删除目标已有对象。上传成功不等于公开可访问。
同服务桶或前缀整理同一 Endpoint/凭据下选择不重叠的源与目标 → 复制、移动或 S3→S3 同步 → 审阅计划。核对目标内容；移动仅在复制验证成功后尝试删源。删除失败时可能保留双副本；不支持跨独立 Endpoint/凭据同步。
受限网络中的私有对象存储先配置独立 SSH Route Proxy → 在 S3 连接选择 SSH 隧道方式并绑定代理 → 打开目标桶 → 上传小型测试文件。跳板需能到达服务；保持原 S3 Host、签名与 HTTPS 身份校验。腾讯 CSP 按指定 HTTP 配置时应明确确认相应风险。
凭据轮换与多环境维护在凭据管理更新认证材料 → 保留连接引用 → 发起一次新的只读操作 → 需要时再验证写入。新操作使用新版本；禁用、过期或解密失败不会回退旧秘密。确认其他使用方迁移后再由管理员停用旧云端密钥。

推荐首次体验

  1. 选择一组专用测试凭据及测试桶，先创建只读连接。
  2. 用一个已知对象验证列举和下载，确认 Region、协议和权限。
  3. 需要上传时单独授予最小写权限，取消连接只读，上传唯一命名的小文件并下载核对。
  4. 再试同步预览，目标使用非空测试前缀，保持删除关闭。
  5. 最后查看传输与同步结果，按逐项状态处理失败；仅清理本次测试对象。

能力边界与当前验证状态

  • 当前范围为图形工作区，不提供应用内 S3 命令解释器或命令入口；本指南 AWS CLI 命令仅用于独立验证。
  • 不包含后台定时备份、Bucket Policy/生命周期编辑、IAM/SSO 自动获取凭据、Token 自动续期、SigV2 或跨独立服务同步。
  • 只读连接限制客户端写入口，服务端仍需正确授权。ACL 请求不保证最终公有/私有访问结果；对象所有权、桶策略和公开访问阻断仍有效。
  • 普通对象删除不永久清理历史版本；删除桶不自动清空桶。新建目录只创建以 / 结尾的零字节标记对象。
  • 同步删除默认关闭，执行前核对具体目标和完整删除明细。同步计划不等同于可在异常退出后自动恢复的传输队列。
  • 异常退出后仅安全传输项可自动恢复；源变化、同名冲突、结果不明和原覆盖项等暂停处理。正常取消、关闭标签和正常退出不会自动恢复。

适用性说明（2026-10-15）：已有 macOS 与隔离 SSH/MinIO 环境的验证记录；正式 AWS、Windows/Linux 原生和部分发布场景尚未全部验证。曾出现正式 AWS 上传被服务端权限拒绝的情况，成功上传仍需按实际授权复验。腾讯公有云、腾讯 CSP 与阿里云的配置示例不代表对应服务已验收通过。使用前应取得交付版本、目标平台与目标环境的验证结果。

参数使用速查 · 填写规则与支持范围

参数使用规则推荐配置
配置名称 / Name凭据名称用于识别；连接名称用于会话树入口。名称不决定 Region 或服务。按云服务、区域与用途命名，连接选择同名托管凭据。
Endpoint / Use HTTPS服务级主机，可含显式端口；不填写桶路径、用户信息、查询或片段。显式 http(s) URL 同步 HTTPS 开关；裸主机保存时按开关补协议。公网使用完整 https:// 地址。CSP 按指定 http://，关闭开关并完成 HTTP 风险确认。
Region签名区域，必填；与桶或私有云签名契约一致，不自动猜测。使用各云服务示例值，实际以桶所在地为准；CSP 由管理员提供。
AK / SK / Token同一身份的一组值；临时凭据必须带 Token。Expiry 使用含时区的真实到期时间。最小权限专用身份。长期密钥 Token/Expiry 留空，临时凭据整体轮换。

签名 / TLS / CA仅 AWS SigV4，不支持 SigV2；HTTPS 校验保持开启，支持自行导入 CA。公网 CA 留空，使用系统信任链；私有 CA 按组织要求导入，不关闭校验。
启用凭据新建凭据默认启用；编辑时可调整。禁用后不应继续调度新的使用请求。仅启用需要使用的记录。不要删除仍被连接引用的凭据。
替换认证材料（编辑时）默认保留已保存密钥；勾选后输入新的完整认证材料。未填 Token 会清空旧 Token。只修改名称/备注时不勾选；轮换时填写 AK/SK 及需要的 Token。

访问方式 / SSH 路由代理支持直连、SSH 代理；代理字段仅 SSH 模式显示，必须选已启用的独立代理。本机可达选择直连；仅跳板可达选择 SSH，不引用旧终端会话。
只读连接启用时限制客户端写入口，不能替代服务端授权。浏览下载勾选；上传验证前按需取消。

传输性能 · 支持参数与推荐配置

在新增或编辑 S3 连接窗口切换到传输性能页。以下设置按连接保存；同一连接多个标签的限速合计计算，上传与下载分别计速。KiB 为 1024 字节，2048 KiB/s 约为 2 MiB/s，不是 2048 Mbit/s。

界面参数默认值支持范围用途与调节建议
工作线程数11–4限制后台工作预算。日常使用和共享 SSH/SFTP 环境保持 1；增加线程不保证网络更快。
传输缓冲256 KiB64–1024 KiB限制传输读写块大小，不是分片大小或全进程内存上限。通常保持 256。
并发传输上限11–4，且不大于工作线程数限制同连接同时执行的文件/扫描任务；不是每个分片都启动一个线程。推荐从 1 开始。
后台等待任务上限641–256限制等待调度的后台任务数，不等于目录文件数上限。队列满时稍后重试。
上传限速2048 KiB/s0–1048576 KiB/s同连接聚合上传速度预算；0 表示不限速。根据可用带宽逐步提高。
下载限速2048 KiB/s0–1048576 KiB/s同连接聚合下载速度预算；与上传分别设置。共享网络不要直接设为不限速。
无进展超时60 秒5–3600 秒连续没有有效传输进展时触发，不是整个文件必须在 60 秒内完成。限速等待和 SFTP 让行不按网络停滞处理。

AWS 中国云 · 单桶权限示例

假设桶名为 my-company-demo-bucket，以下策略允许列目录、下载、上传及分段上传相关操作，不包含删除对象。将所有桶名替换为实际值；中国区 ARN 前缀为 arn:aws-cn:。

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "ListTargetBucket",
      "Effect": "Allow",
      "Action": ["s3:ListBucket", "s3:GetBucketLocation", "s3:ListBucketMultipartUploads"],
      "Resource": "arn:aws-cn:s3:::my-company-demo-bucket"
    },
    {
      "Sid": "ReadWriteTargetObjects",
      "Effect": "Allow",
      "Action": ["s3:GetObject", "s3:PutObject", "s3:AbortMultipartUpload", "s3:ListMultipartUploadParts"],

  ]
}

为什么使用 SSH 路由 · 场景与解决的问题

SSH 路由适用于本机到不了对象存储，但一台获授权的 SSH 主机可以访问的环境。XTermPro 将本机发起的 S3 请求经这台主机转发，文件仍由本机选择、上传和下载，不需要先把文件复制到跳板再执行工具。

访问路径

本机 XTermPro → SSH 加密隧道 → SSH 跳板 → S3 / COS / CSP / OSS

SSH 凭据用于登录跳板；S3 凭据用于访问对象存储。两种身份分别校验，跳板能登录不代表有权读取或写入桶。

哪些场景需要它

场景直接访问遇到什么问题SSH 路由如何处理仍需确认什么
私有云或内网对象存储办公电脑无法到达私有地址或内部服务，直接请求超时。经可访问存储的内网 SSH 主机转发，不要求将存储入口开放到公网。本机可达 SSH 主机；跳板可达服务和所需桶域名；S3 权限有效。
存储入口仅允许指定网络出口本机出口不在服务侧允许的范围，直接请求被拒绝。按已有授权，经指定网络内的跳板访问；服务通常看到跳板侧的实际出口。由网络管理员确认跳板出口在允许范围；不能假定使用 SSH 会绕过策略。
异地运维或临时办公当前电脑没有直达业务网络的路径，但已有受控 SSH 入口。复用获授权跳板作为当前 S3 连接的访问路径，减少“远端中转文件再搬回”的步骤。组织允许该接入方式；跳板的可用性、带宽和访问权限满足任务要求。
本机文件上传到受限桶本机直连失败；先传文件到跳板会产生临时副本及额外操作。本地文件由 XTermPro 经路由上传到目标桶，无需先在跳板手工落盘。实际使用小文件验证上传、下载与内容；跳板转发能力不等于对象写权限。
多个业务连接使用同一跳板每个连接重复维护跳板参数，变更时容易遗漏。将 SSH Route Proxy 独立保存，由各 S3 连接选择引用；K8s 也可按自身配置引用该代理。修改共享代理会影响引用它的连接；分别测试业务目标，不把某一目标成功视作所有目标成功。

Direct、SSH 路由与 VPN 怎么选

已有网络条件选择原因
本机可以直接访问对象存储Direct无需额外跳板；公网配置继续使用 HTTPS。

它不解决哪些问题

  • 不会赋予桶权限：IAM、CAM、RAM、桶策略、KMS 或私有云权限拒绝，仍需由授权负责人处理；403 不一定是路由故障。
  • 不会修正服务参数：Endpoint、Region、桶名、签名版本、临时 Token 错误，仍会导致请求失败。
  • 不会自动获得服务器信任：首次连接或指纹变化时，应通过可信渠道核对 SSH 主机身份。
  • 不是全局 VPN：仅为选择该代理的业务连接提供路由，不意味着电脑上的所有应用都经该跳板访问。
  • 不保证提速：额外网络跳数与跳板带宽可能增加时延、限制吞吐，应在实际任务规模下验证。
  • 不改变失败策略：SSH 不可用时停止对应路径，不自动退回 Direct；需要明确修改连接并重新验证。

SSH 加密与 HTTPS 的关系

SSH 保护本机到跳板这一段，HTTPS 保护 S3 请求与对象存储之间的 TLS 通信。公网 S3/COS/OSS 使用 SSH 路由时，仍保持 Use HTTPS 勾选和证书校验。

腾讯私云 CSP 按指定配置使用 HTTP：SSH 隧道可以保护本机到跳板的一段，跳板到 CSP 服务的一段仍无 HTTPS 传输加密。不能把“用了 SSH”表述为全程 HTTPS；应按该私有环境的网络要求确认使用范围。

怎样判断配置成功

  1. SSH 连接测试：确认跳板认证及代理建立成功；这一步不代表 S3 可用。
  2. S3 只读访问：从绑定代理的连接进入指定桶，列举对象并下载已知文件；结合请求错误判断路由、服务和权限。
  3. 按需验证写入：上传唯一命名的非敏感测试文件，再下载核对内容，检查传输结果。
  4. 记录实际路径：记录客户端版本、所选路由代理、服务、Region、桶和测试结果；不要在记录中保存密码、私钥或 S3 密钥。

本节说明 SSH 路由的访问路径与使用边界；实际业务环境仍需按下述步骤验证连通性、权限及传输结果。

SSH 路由 · 访问受限网络中的 S3

Direct 示例适用于本机可访问存储的环境。需要跳板时，使用独立 SSH Route Proxy；不是选择已有终端会话，也不在跳板执行 s3cmd。

  1. 打开 配置 → SSH 隧道管理 → SSH Route Proxy，新增代理，填写名称、SSH 主机、端口、用户及密码或私钥。
  2. 点击连接测试，首次连接时按组织提供的可信信息核对主机指纹，成功后保存。
  3. 编辑 S3 连接，将访问方式切换为 SSH 代理，选择已启用的 SSH Route Proxy，再保存。
  4. 打开 S3 连接，验证目标桶列表、已知对象下载及需要的写操作。SSH 测试成功只说明 SSH 认证和代理建立，不说明 S3 授权与可达性。

SSH 路由失败或断开后不会自动直连；旧 SSH 会话引用须在编辑连接时重新选择路由代理。公网 HTTPS 配置经 SSH 路由时仍保留原服务域名、SigV4 与 TLS 身份校验；不会因使用隧道而取消校验。

打开连接 · 对象浏览与验证

打开连接后，确认右侧选中的 Bucket、Prefix 与预期一致，再刷新对象列表。可在 Object browser 浏览对象，在 Transfers 查看传输，在 Sync tasks 查看同步任务；同步任务的操作步骤见“同步与传输结果”。
